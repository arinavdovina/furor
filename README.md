# Furor VK · 14 дней для вашего сообщества

Готовый сайт для участников: оформление и ведение VK-сообщества, личность преподавателя, публикации, общение и предложения.

## Что внутри

- Программа на 14 дней и практические задания.
- Пять памяток о старте, оформлении, разделах VK, первых постах и рубриках.
- Пять полных учебных примеров стартовых постов и шаблон закрепа.
- Диагностика: 12 вопросов, четыре направления и три приоритета.
- Конструктор постов с 50 шаблонами и ещё 10 анкет для промптов по задачам VK.
- Встроенные PDF, текстовые шаблоны, трекер и личные заметки.

## Файлы

- `index.html` — весь сайт: тексты, стили, JavaScript, изображения, шрифты и скачиваемые материалы. Работает без сборки и установки пакетов.
- `.nojekyll` — публикация готовых статических файлов.
- `.gitignore` — исключение служебных файлов компьютера.
- `licenses/OFL.txt` — лицензия встроенного шрифта Furor Serif, адаптированного из STIX Two Text.

## Как опубликовать через GitHub Pages

1. Создайте репозиторий, например `furor-vk-14-days`. Для GitHub Free используйте публичный репозиторий.
2. Загрузите **содержимое этой папки** в корень репозитория. Файл `index.html` должен находиться непосредственно в корне, рядом с `README.md`, а не во вложенной папке. ZIP нужно сначала распаковать.
3. Сохраните файлы в ветке `main`.
4. Откройте **Settings → Pages**.
5. В **Build and deployment → Source** выберите **Deploy from a branch**.
6. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
7. Дождитесь завершения публикации. Адрес сайта появится в разделе Pages. Передайте участникам именно этот адрес.

Инструкция сверена с [документацией GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Как открыть и обновлять

Для локального просмотра откройте `index.html` в браузере. Для обновления размещённого сайта замените `index.html` в репозитории новой версией и сохраните изменение в выбранной ветке. Содержимое встроенных материалов находится внутри этого файла.

Навигация использует адреса вида `#day-1` и `#prompt-audit`; дополнительная настройка маршрутов не нужна. Ссылки на внешнюю справку и работа с выбранным сервисом ИИ требуют интернета.

## Записи участников и промпты

Заметки, отметки дней, трекер и поля анкет сохраняются в браузере участника на его устройстве. На GitHub эти записи не отправляются. В разделе «Мои записи» можно скачать заметки и трекер; собранный промпт можно скопировать или скачать отдельно.

При переходе с локального файла на опубликованный адрес записи автоматически не переносятся: браузер хранит их отдельно для разных адресов. Перед переходом скачайте нужные записи из прежней версии.

Конструкторы собирают текст запроса. Участник сам вставляет его в выбранный чат с ИИ и проверяет полученный ответ. Ключ API для работы сайта не нужен.
